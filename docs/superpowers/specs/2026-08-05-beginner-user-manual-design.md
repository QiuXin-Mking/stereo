# 零基础使用手册设计

## 目标读者

手册面向只有初中学历、不会写代码、不会使用 Linux 命令的现场操作员。技术人员也能通过末尾附录完成服务启动、备份检查、试运行求解和产物交付。

## 文档位置

- 新建 `docs/零基础使用手册.md`。
- 在仓库根目录 `README.md` 开头附近增加手册入口。

## 内容结构

### 普通操作员部分

1. 用一句话说明系统用途。
2. 列出相机、RK3588、电脑、棋盘和网络等准备物品。
3. 说明通电、连接相机、打开浏览器地址的顺序。
4. 用页面上的真实名称解释状态、采集进度、引导文字、预览和按钮。
5. 按当前固定 32 组顺序解释如何移动棋盘。
6. 说明每次只点击一次“手动拍摄”，等待进度增加后再移动。
7. 列出完整入镜、无反光、无模糊、保持静止等合格标准。
8. 说明完成 32 组后的交接动作，并明确当前网页“开始求解”尚未接入手动素材处理，普通操作员不要自行点击。
9. 提供页面打不开、没有画面、进度不增加、服务停止等常见故障处理。
10. 列出禁止事项和需要联系管理员的情况。

### 管理员附录

1. SSH 登录 RK3588。
2. 启动 Web 服务和建立本地 SSH 隧道。
3. 检查 API 状态、当前会话和备份目录。
4. 说明当前棋盘为 `5×8` 内角点，方格尺寸必须实测。
5. 说明手动素材的角点检测、异常样本剔除和离线求解流程。
6. 列出 YAML、JSON、NPZ、校正映射、质量报告和预览文件的位置与用途。
7. 给出通过标准：左右单目 RMS、双目 RMS、极线误差和有效样本数量。

## 写作规则

- 一句话只表达一个动作。
- 每一步使用编号，并写清楚“看到什么才算成功”。
- 首次出现的专业词必须用生活化语言解释。
- 普通操作部分不出现 Python、OpenCV 矩阵或代码原理。
- 危险或不可恢复的操作不提供给普通操作员。
- 不声称网页已经自动完成当前尚未集成的手动素材求解。

## 验证

- 对照当前 Web 页面核对所有按钮和字段名称。
- 检查 32 组姿态顺序与程序一致。
- 检查所有命令和路径与 RK3588 当前部署一致。
- 检查 README 链接可正确指向手册文件。
- 搜索并消除“按实际情况”“自行处理”等模糊指令。
