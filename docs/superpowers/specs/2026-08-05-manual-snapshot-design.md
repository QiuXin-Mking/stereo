# RK3588 手动拍摄最小设计

## 目标

在自动棋盘检测暂时失败时，允许用户从 Web 页面手动保存当前双目 SBS 帧，先完成多姿态素材采集，后续再离线检测角点和求解。

## 交互

- 控制区新增“手动拍摄”按钮。
- 状态区新增“手动素材”，显示 `N / 32`。
- 点击后，工作线程在下一帧保存一次快照；连续点击对应连续的独立拍摄请求。
- 成功后页面提示保存数量；写盘失败时进入错误状态并显示原因。

## 数据与安全边界

- 每次手动拍摄保存完整 SBS JPEG、左眼 PNG、右眼 PNG，目录为当前会话的 `manual/`。
- 文件以递增的四位编号命名，避免覆盖。
- 手动素材不加入 `_accepted`，不增加自动采集进度，也不允许作为缺少角点的样本进入求解器。
- 自动检测、自动采集和现有控制按钮保持原行为。

## 数据流

Web `manual_capture` 动作只增加待拍请求计数。相机工作线程读取下一帧后消费一个请求并完成三张图写盘，再更新 `manual_pairs` 状态。这样 HTTP 线程不会直接访问相机帧，也不会保存重复的旧预览图。

## 验证

- 单元测试确认 Web 页面包含按钮并发送正确动作。
- 引擎测试确认动作排队、下一帧落盘、计数增加且自动有效样本数不变。
- 全量测试通过后同步 RK3588，重启服务，并通过页面/API 与远端文件验证一次真实手动拍摄。
