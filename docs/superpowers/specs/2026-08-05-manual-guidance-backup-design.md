# 手动姿态引导与会话备份设计

## 目标

在自动角点检测不可用时，以手动拍摄数量驱动完整的 32 组姿态引导。每次 Web 服务重新启动前，将上一轮素材真正复制备份到独立目录，同时新页面只显示本轮采集进度。

## 32 组引导顺序

- 1–2：中央正对
- 3–4：左侧
- 5–6：右侧
- 7–8：上方
- 9–10：下方
- 11–12：左上角
- 13–14：右上角
- 15–16：左下角
- 17–18：右下角
- 19–20：向左偏航
- 21–22：向右偏航
- 23–24：向上俯仰
- 25–26：向下俯仰
- 27–28：顺时针旋转
- 29–30：逆时针旋转
- 31：靠近
- 32：远离

页面提示的是下一组应拍姿态。每次手动拍摄写盘成功后，进度加一并切换下一条提示。达到 32 组后提示“本轮采集完成”，拒绝更多手动拍摄。

## 页面

- 删除“手动素材”卡片。
- “采集进度”显示 `manual_pairs / target_pairs`，不再显示自动角点样本数量。
- 保留实时预览和“手动拍摄”按钮。
- 自动检测状态不再覆盖手动姿态引导。

## 启动备份

- 仅 Web 模式启动时执行。
- 创建新会话前，查找 `sessions/` 中时间戳最新且包含 `manual/` 的上一轮会话。
- 使用完整目录复制，将其备份到项目根目录的 `backups/<原会话时间戳>/`。
- 原 `sessions/<时间戳>/` 不删除、不移动；目标备份已存在时跳过，禁止覆盖。
- 备份完成后创建新的时间戳会话，因此页面从 `0/32` 开始且看不到上一轮计数。

## 验证

- 单元测试覆盖 32 组边界提示、完成后拒绝第 33 组，以及 Web 页面只显示统一采集进度。
- CLI 测试覆盖上一轮会话复制到 `backups/`、原文件仍存在、已有备份不被覆盖。
- 本地与 RK3588 全量测试通过后重启服务，确认旧 56 组被备份、新页面为 `0/32` 并显示“中央正对”。
