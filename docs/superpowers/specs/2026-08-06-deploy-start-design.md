# RK3588 服务与 Codex 本地隧道启动设计

## 目标

在工程的 `deploy/start.sh` 中提供一键启动，使 Codex 内置浏览器通过 `http://127.0.0.1:18765/` 访问 RK3588 上的标定网站。

## 连接方向

使用 SSH 本地端口转发，而非 `-R` 反向转发：

`127.0.0.1:18765 -> SSH root@192.168.100.200 -> 127.0.0.1:8765`

## 启动流程

1. 验证 `root@192.168.100.200` 可通过密钥非交互登录。
2. 请求 RK3588 本机的 `127.0.0.1:8765/api/status`。
3. 服务未运行时，从 `/root/stereo_chessboard_calibrator` 启动 Web 标定服务；已运行时不重启，以保留当前会话。
4. 检查本机 `18765` 端口。已是可用隧道时直接复用；否则建立 `ssh -N -L` 转发。
5. 等待本地 URL 返回 HTTP 成功状态，然后打印可点击地址。

## 状态与错误

- 运行时 PID 和日志保存在 `deploy/.runtime/`，该目录不进入 Git。
- SSH 不可达、远端服务启动失败、本地端口被其他程序占用时，脚本应明确报错并退出。
- 脚本重复执行必须幂等，不会重复启动服务或隧道。

## Web 界面

移除“停止服务”按钮，避免用户在标定界面误触后断联。后端 `stop` 动作保留给维护和测试使用。

## 验收

- Web 页面不再包含“停止服务”按钮。
- 远端服务未运行时，执行 `deploy/start.sh` 可启动服务和隧道。
- 远端服务已运行时，脚本不会将其重启。
- 重复执行脚本不会产生多个隧道。
- `curl http://127.0.0.1:18765/api/status` 返回标定状态。
