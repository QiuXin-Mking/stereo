# 低照度混合自动/手动采集设计

## 目标

在低照度、实时棋盘检测不稳定的环境中，既保留姿态引导自动采集，又保证操作员可以随时强制保存样本。

## 核心规则

- 自动采集默认开启，可在页面关闭。
- “手动拍摄”始终可用，一按必保存，不受角点、姿态、亮度或模糊检测结果阻断。
- 保存成功不等于标定有效；界面必须分开显示“已保存”和“已检测有效”。
- 所有手动与自动样本最终进入同一套求解前处理和质量筛选。

## 手动拍摄

1. 用户按下一次按钮，系统将请求排入队列，不会因当前帧角点检测失败而拒绝。
2. 采集连续 5 帧，以左右眼较差一侧的清晰度作为该帧分数，保存分数最高的一帧。
3. 同时保存原始 SBS、左眼图、右眼图和元数据。元数据记录手动来源、时间、清晰度和当时检测状态。
4. 文件全部写入成功后才增加“已保存”计数。

## 自动拍摄

- 左右眼同时检测到完整 `8×5` 内角点后，计算归一化中心、面积、平面旋转和透视特征。
- 样本归入 32 个姿态槽位：中央正对 2 组；左、右、上、下及四角各2组；左右偏航和上下俯仰共8组；顺/逆时针旋转共4组；近/远距离各1组。
- 样本符合未完成槽位，且连续稳定 0.6 秒后自动保存。
- 页面提示当前最缺的姿态，但不强制拍摄顺序；当前姿态匹配任何未完成槽位都可保存。
- 曝光、模糊、贴边、不完整和重复检测只限制自动保存，不限制手动保存。

## 求解前处理

1. 读取本轮全部已保存样本，不区分手动或自动来源。
2. 先在原始灰度图上检测角点；失败时使用 CLAHE 局部对比度增强后重试。
3. 只有左右眼同时检到完整角点，尺寸一致并通过基础质量检查的样本才进入求解。
4. 求解器继续使用重投影/极线误差剔除几何离群样本。
5. 有效样本少于 20 组或姿态覆盖不足时，不输出“通过”，页面显示不合格编号和建议补拍姿态。

## 界面状态

- “已保存”：文件已安全写入的手动加自动样本总数。
- “检测有效”：当前能同时检出左右角点的样本数，该数在求解前可更新。
- “自动采集”开关：默认开启，关闭后仅停止自动保存，不影响预览、提示和手动拍摄。
- 手动保存后明确显示“已强制保存第 N 组”，即使当时角点未检测成功。

## 验收标准

- 使用无棋盘或角点检测失败的画面点击手动拍摄，仍会产生一组完整文件并增加已保存计数。
- 5 帧中存在清晰度差异时，保存左右眼最差清晰度分数最高的帧。
- 自动采集开关不会影响手动拍摄。
- 页面同时显示已保存数和检测有效数，两者不再共用一个计数。
- 求解时原始检测失败的样本会使用 CLAHE 重试，仍失败时列入补拍清单。
