# README 界面截图设计

## 目标

在 README 的 RK3588 浏览器采集章节展示一张真实、可长期随仓库显示的 Web 控制台图片，帮助零基础用户认识页面。

## 截图状态

- 重启 RK3588 Web 服务，创建新会话。
- 页面状态为 `capturing`。
- 采集进度为 `0/32`。
- 引导文字为“第 1/32 组：棋盘放在中央并正对相机”。
- 截图包含状态卡、实时 SBS 预览、引导文字、质量区域和全部按钮。
- 不伪造、不合成、不包含 stopped、连接失败或旧的“手动素材”卡片。

## 文件与 README

- 图片保存为 `docs/images/rk3588-web-ui.png`。
- README 使用相对路径 `![RK3588 Web 标定界面](docs/images/rk3588-web-ui.png)`。
- 图片放在“RK3588 浏览器采集”章节的启动说明之后。
- 图片下用一句话解释页面会显示设备模式、单眼分辨率、采集进度、姿态提示和实时预览。

## 验证

- 目视确认图片中文字清楚且页面完整。
- 检查截图中的进度和引导状态符合新会话。
- 检查 README 相对路径存在且文件为有效 PNG。
- 提交后检查 GitHub `main` 已包含图片和 README 引用。
