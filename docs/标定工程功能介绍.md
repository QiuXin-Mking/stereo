# 标定工程功能介绍

## 一、最终输出结果

标定通过后，产物写入 `sessions/<会话时间>/results/<结果目录>/`：

### 标定参数

三份格式内容一致，供不同语言读取：

| 文件 | 用途 |
|---|---|
| `stereo_calibration.yaml` | OpenCV/C++ 标定参数 |
| `stereo_calibration.json` | 跨语言参数及质量指标 |
| `stereo_calibration.npz` | Python/NumPy 标定参数 |

标定字段如下：

| 标定量 | 字段名 |
|---|---|
| K1（左内参矩阵） | `left_camera_matrix` |
| K2（右内参矩阵） | `right_camera_matrix` |
| D1（左畸变系数） | `left_distortion` |
| D2（右畸变系数） | `right_distortion` |
| R（双目旋转矩阵） | `rotation` |
| T（双目平移向量，基线） | `translation` |
| E（本质矩阵） | `essential` |
| F（基础矩阵） | `fundamental` |
| R1（左校正旋转） | `rectification_left` |
| R2（右校正旋转） | `rectification_right` |
| P1（左投影矩阵） | `projection_left` |
| P2（右投影矩阵） | `projection_right` |
| Q（视差转深度矩阵） | `disparity_to_depth` |

补充说明：

- 畸变使用 OpenCV pinhole 五参数模型，顺序为 `k1, k2, p1, p2, k3`。
- 相机焦距与主点 `fx, fy, cx, cy` 分别位于 K 矩阵的 `(0,0)`、`(1,1)`、`(0,2)`、`(1,2)`。
- 基线长度为 `norm(T)`。

### 校正映射

- `rectify_maps.yml.gz`：OpenCV/C++ 左右校正映射。
- `rectify_maps.npz`：Python/NumPy 左右校正映射。

### 质量报告

`quality_report.json`：单目 RMS、极线误差、有效/剔除样本数。

### 校正预览

`rectification_preview.png`：带水平极线的效果图，用于人工确认左右对应点落在同一条水平线上。

其中 `Q` 矩阵、基线（`norm(T)`）、深度物理尺度都由实测方格边长决定，因此交付时必须同时记录分辨率、方格尺寸与 RMS 报告，且标定后不得改变左右镜头相对位置。

## 二、工程定位

这是一套面向**单路 UVC 左右拼接（SBS）双目相机**的标定工具。所谓"单路 SBS"，是指相机只用一个 USB 口、一个 `/dev/video0` 设备，单帧画面里左右两个镜头并排拼接（如 `3840×1080`，左右各 `1920×1080`）。

标定的目的，是让程序知道：

- 每只镜头"怎么看东西"（内参、畸变）；
- 两只镜头之间相差多远、朝什么方向（外参 R/T）；
- 左右画面如何对齐（校正映射）。

有了这些，后续才能做立体匹配、计算视差、恢复深度。整套采集与求解都在 RK3588 板端完成，Mac 只负责浏览器和下载结果。

## 三、使用流程

管理员在 RK3588 上运行：

```bash
./calibrate --web --device /dev/video0 --port 8765 --square-mm 20
```

> `--square-mm` 必须用毫米尺实测棋盘方格边长，不能直接套用设计尺寸。

操作员浏览器访问页面，必要时经 SSH 隧道转发：

```bash
ssh -N -L 18765:127.0.0.1:8765 root@<RK3588-IP>
```

流程分两种模式：

1. **OpenCV Chessboard（纯双目）**：按页面蓝框提示逐组摆放棋盘，点击"手动拍摄"保存 32 组（每组存 `xxxx_sbs.jpg` + 左右 PNG），保证左右眼同时看到完整棋盘。拍满后点"开始求解"，系统自动走"角点检测 → 质量初筛 → 双目标定 → 误差检查 → 剔除异常样本 → PASS 或补拍"链路。
2. **Kalibr Camera+IMU（world intelligent 相机）**：点"开始录制"，持续移动棋盘并绕 X/Y/Z 三轴转动 60–90 秒，再"停止录制 → 检查数据 → 开始 Kalibr 求解"，在容器内完成相机与内置 IMU 的联合标定。

## 四、组件职责

工程按职责拆成若干 Python 模块（`src/stereo_calibrator/`）：

| 组件 | 职责 |
|---|---|
| `camera_backend.py` / `camera_profile.py` | 相机接入与设备识别。前者探测 V4L2 设备、枚举并打开 MJPEG `4000×1200` 或 `3840×1080` 分辨率；后者识别特殊型号 `world intelligent` 相机——当设备名、`4000×1200` 分辨率、左侧 160 像素码带特征三项同时满足时，按 `[0:160]` 码带（丢弃）、`[160:2080]` 左眼、`[2080:4000]` 右眼的固定布局裁剪，而不是简单等分。 |
| `sbs.py` | 把 SBS 帧按中线拆成左右两张独立图，支持 `--swap-eyes` 左右互换。 |
| `detector.py` | 用 OpenCV `findChessboardCornersSB` 做亚像素棋盘内角点检测（默认 `5×8` 内角点，即 6×9 方格）。 |
| `quality.py` | 采集时对每张图做模糊（拉普拉斯方差）、反光/过曝（裁剪比例）、越界（边缘留白）、姿态新颖度等初筛。 |
| `pose_slots.py` | 姿态引导。按中央、上下左右、四角、偏航/俯仰/旋转、远近共 16 个槽位、每槽 2 组，指导操作员逐组摆放棋盘，保证姿态覆盖充分。 |
| `solver.py` | 核心求解。用左、右内角点做单目标定得到 K/D，再 `stereoCalibrate` 求出双目 R/T、E/F，`stereoRectify` 算出 R1/R2/P1/P2/Q，并生成校正映射。 |
| 结果检查 | 按重投影误差（单目 RMS ≤ 0.7px）与极线误差（中位数 ≤ 0.35px、P95 ≤ 1.0px）剔除几何异常样本，输出 PASS/RETAKE 结论。 |
| `exporter.py` | 把结果导出成 YAML / JSON / NPZ 三种格式及校正映射文件。 |
| `cli.py` / `headless.py` / `web.py` | 三个入口。`cli.py` 解析参数；`web.py` 提供基于 `ThreadingHTTPServer` 的网页界面（实时预览、进度、按钮）；`headless.py` 支持无界面自动采集。 |
| `kalibr_runtime/` | 为 `Kalibr Camera+IMU` 联合标定准备的**最小 ARM64 Docker 容器**（固定 Kalibr 提交），在容器内跑 Kalibr/rosbag，RK3588 主机不装 ROS。 |
| `boards/` / `configs/default.yaml` / `examples/cpp/` / `deploy/` | 分别存放棋盘规格/打印 SVG、默认参数（目标 32 组、最少 20 组、质量阈值）、C++ 读取示例、部署脚本。 |
